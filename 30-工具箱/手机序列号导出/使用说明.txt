手机序列号导出 —— 使用方法
=====================================================

一、安卓手机
  1. 手机：设置 -> 关于手机 -> 连续点 7 次「版本号」-> 出现「开发者选项」
          -> 进入开发者选项 -> 打开「USB 调试」
  2. 用数据线连到电脑：手机上选「传输文件 / MTP」，弹窗点「允许 USB 调试」
  3. 双击「查序列号.bat」
  结果会显示在屏幕上，同时导出到桌面：手机序列号_日期_时间.txt

二、iPhone
  1. 用数据线连到电脑：手机上点「信任此电脑」，并保持屏幕解锁
  2. 双击「查序列号.bat」
     说明：电脑没装 iPhone 专用工具时，脚本只能读到 UDID（设备唯一编号），
     不是「序列号」。想看 iPhone 的真序列号：
       - 手机上自己看：设置 -> 通用 -> 关于本机 -> 序列号
       - 电脑上看：装「爱思助手」这类工具；或装 libimobiledevice 后再跑本脚本

三、什么都没读到
  1. 换一个 USB 口、换一根数据线（很多线只能充电、不能传数据）
  2. 确认手机已解锁、屏幕亮着
  3. 换一条路：双击「查序列号-自动装ADB.bat」（会自动下载 adb，约 10MB）

四、文件说明
  get-phone-serial.ps1          主脚本（bat 会调用它）
  查序列号.bat                   普通运行
  查序列号-自动装ADB.bat         电脑没装 adb 时用这个
  使用说明.txt                   本文件
  导出结果                       桌面上的「手机序列号_日期_时间.txt」

五、想自己看一眼（不用脚本）
  安卓：设置 -> 关于手机 -> 状态信息 / 全部参数 -> 序列号
  iPhone：设置 -> 通用 -> 关于本机 -> 序列号
  不分机型：拨号盘输入 *#06#（显示 IMEI）；手机包装盒背面的 S/N 就是序列号
