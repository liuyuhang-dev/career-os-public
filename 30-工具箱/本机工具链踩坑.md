# 本机工具链踩坑清单

> 2026-11 做作品集站和简历时踩过的，每条都验证过解法。换机器或换项目时直接翻。

## 1. git push 卡住几分钟没输出

**现象**：`git push` 敲下去，光标不动，也不报错，等五六分钟。

**原因**：仓库继承了 `credential.helper=manager`（Git Credential Manager）。它不知道 `gh` 已经拿到的 token，会等弹窗，而你根本没看到弹窗。

**解法**：让 git 用 gh 做凭据助手，写绝对路径。

```bash
git config --local credential.helper ""
git config --local credential.https://github.com.helper \
  '!"D:/toolchains/gh-cli/bin/gh.exe" auth git-credential'
```

修完 `git ls-remote` 几秒就返回。**判断标准：10 秒没响应就是凭据问题，不是网络。**

## 2. 推了新版本，页面还是旧的

**现象**：文件确实传上去了，`curl` 能看到新内容，浏览器却显示旧版。

**原因**：GitHub Pages / COS 都带 `Cache-Control: max-age=600`，同名文件在这个窗口内直接用缓存。

**解法**（二选一）：

- 页面里给静态资源加版本号：`style.css?v=20261112`
- 或强刷：`Ctrl+Shift+R`（普通 F5 不够）

**排查顺序**：先 `curl` 看服务器内容对不对 → 对就是缓存 → 再去查代码。

## 3. Word 转 PDF（不用装任何东西）

机器上有 Office 就能用 COM：

```powershell
$w = New-Object -ComObject Word.Application
$w.Visible = $false
$d = $w.Documents.Open('D:\path\简历.docx')
$d.SaveAs2('D:\path\简历.pdf', 17)
$d.Close(); $w.Quit()
```

`17` 是 PDF 格式编号。

**坑**：目标 PDF 正在阅读器里打开时，`SaveAs2` 会失败（文件被占用）。先关窗口，或换个文件名。

## 4. python-docx 设中文字体报 None

**现象**：`run._element.rPr.rFonts.set(...)` 报 `'NoneType' object has no attribute 'set'`。

**原因**：`rPr` 或 `rFonts` 还没创建。直接访问属性拿到的是 None。

**解法**：用 `get_or_add_*`：

```python
run._element.get_or_add_rPr().get_or_add_rFonts().set(
    qn("w:eastAsia"), "微软雅黑")
```

样式对象同理：`st.element.get_or_add_rPr()`。

## 5. 把文档压进一页

**做法**：不要凭感觉缩，用数据驱动。

```python
import pymupdf
d = pymupdf.open("x.pdf")
print("pages:", d.page_count)
print("溢出:", d[1].get_text().strip()[:80] if d.page_count > 1 else "无")
```

**调整顺序**（从优到劣）：

1. 删重复内容——同一件事在两处出现，删一处
2. 合并并列项——两条同类 bullet 合成一条
3. 去掉单独成节的小内容（如教育单开一节 → 压成一行）
4. 缩段间距
5. 最后才缩字号 / 边距

**下限**：正文 8.8pt、下边距 0.6cm。再小打印就难看了。

## 6. 快速看 PDF 长什么样

```python
import pymupdf
for i, page in enumerate(pymupdf.open("x.pdf")):
    page.get_pixmap(dpi=130).save(f"_pv{i+1}.png")
```

130 dpi 足够看清排版，文件也不大。

## 7. 应用内浏览器打不开某些域名

**现象**：ZCode 右侧预览窗打开腾讯云 COS 地址，停在 `about:blank`；同一地址 `curl` 是 200。

**结论**：那个 webview 对 `*.myqcloud.com` 有问题，但能正常打开 `github.io` 和 `example.com`。

**影响**：**给别人看的链接优先用 `*.github.io`**，别用 COS 直链。

## 8. gh CLI 不在 PATH

`gh auth login` 能跑通，但换个 shell 就找不到 `gh`。

**解法**：每次显式加路径，或写进脚本开头：

```bash
export PATH="/d/toolchains/gh-cli/bin:$PATH"
```
