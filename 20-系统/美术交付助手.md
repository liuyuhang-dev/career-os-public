# 美术交付助手：把「交文件」变成一个不会漏的系统

> 一句话：美术只需要把文件拖进一个文件夹，剩下的命名校验、版本管理、提交、留痕、退回全部自动完成。

## 背景与约束

| 项 | 内容 |
|---|---|
| 当时的状态 | 美术资源走 SVN。交付靠口头通知 + 人工提交：漏交没人发现、同名文件互相覆盖、半截文件被提交、出了问题查不到是谁哪次交的 |
| 规模 | 10 个交付监控目录；内外部美术十余人；每周数十次交付 |
| 硬约束 | ① 美术不会也不该学 SVN ② 不能改变他们的工作习惯，最多让他们多做一个动作 ③ 没有服务器的开发权限，只能在客户端侧解决 ④ 必须沿用已有 SVN 库结构，不能迁移 |
| 我的角色 | 设计 + 实现 + 推动落地 |

## 设计

核心思路：**把「交付」这件事降级成「往一个文件夹里放文件」**，其余全部由机器承担。

```
美术 ──拖入──▶ 收件箱（只写）
                  │
                  ├─ 命名合规 ──▶ 解析出 单号/资源名/用途
                  │                  │
                  │                  ├─ 文件"传完"判定（大小+mtime 连续 2~3 轮不变）
                  │                  ├─ 同名不覆盖 → 自动 v001/v002
                  │                  └─ SVN 提交 + 工单号回填
                  │
                  └─ 命名不合规 ──▶ 待修改/ + !说明.txt（告诉他哪里不对）
```

三条设计原则：

1. **文件名即数据结构。** 不做表单、不做网页，用 `单号_资源名_用途.ext` 编码全部信息。零学习成本，且对任何工具都可见。
2. **先确认，再搬运。** 文件还在拷贝时大小会变，只有连续多轮稳定才认为是"传完了"——这一条消灭了最难查的半截文件问题。
3. **失败要能自己恢复。** 断网、文件被占用、SVN 锁冲突都不丢任务：失败的文件进 5 分钟退避队列，状态落盘，进程重启后继续。

| 决策 | 选了 | 没选 | 为什么 |
|---|---|---|---|
| 交付入口 | 一个只写共享文件夹 | 教美术用 SVN 客户端 | 培训成本远高于开发成本，且一定会有人做错 |
| 元数据来源 | 文件名编码 | 表单/网页/Excel 登记 | 多一步操作就多一次漏填 |
| 触发方式 | 定时快照 diff | 文件系统事件 | 网络盘上 FileSystemWatcher 不可靠，漏事件 |
| 冲突处理 | 自动递增版本号 | 覆盖 / 报错阻断 | 覆盖会丢资源；阻断会让人卡住 |
| 退回方式 | 移到「待修改」并附说明 | 弹窗报错 | 弹窗关掉就忘，文件放错地方才会被处理 |

## 落地过程

1. **先做单点验证**：本地目录 + 一个监视脚本，跑通"拖进去 → 自动归类 → 记台账"，确认判定逻辑不误伤。
2. **再解决"传完"判定**：早期直接收文件，导致半截文件被提交。改成快照对比后稳定。
3. **补退回与留痕**：命名不合规不能静默丢弃，必须有可见的退回区和说明，否则美术以为交付成功了。
4. **最后接 SVN 与通知**：提交、工单号回填、托盘通知、看门狗自恢复。

阻力最大的一步不是技术，是**让美术相信"拖进去就等于交了"**。前期故意保留了一个可见信号：收件箱变空 = 全部处理完毕。

## 结果

- 覆盖 10 个交付监控目录，资源交付从「人工提交 + 口头确认」变为「自动同步」。
- 漏交、重复提交、同名覆盖需要人工追查的情况基本消失。
- 每次交付都有台账：时间、来源机器、原始文件名、单号、归档路径、版本、结果。
- 命名不合规在投递当场被退回，不再流到下游。

## 如果重来

- **太晚做"可见性"**。前两周美术不知道系统在干什么，因为没有任何反馈。后来加了托盘通知和状态文件才好。工具的第一版应该先解决"让人知道它在工作"，再解决"它工作得多好"。
- **原型没做整夹交付**，拖文件夹会被跳过。真实使用里美术经常一次交一整套，这是明显的缺口。
- **"交付人"早期只记机器名**，能定位到工位但定位不到人。正确做法是投递口按人分子文件夹，让目录结构承载归属。

## 可复用件

这套「**只写投递口 + 文件名即结构化 + 传完判定 + 自动版本 + 退回区**」的模式，适用于任何"非技术人员向系统交付文件"的场景：外包交付、素材入库、法务合同、财务票据。核心不是 SVN，是**把协议藏进目录结构里**。
