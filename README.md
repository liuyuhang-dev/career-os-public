## 三条规矩

1. **只存能力，不存公司数据。** 方法、结构、决策可以带；需求原文、客户数据、内网地址、真实人名不带。
2. **每条记录必须能回答"我当时怎么想的"。** 只写结果的是周报，写清约束和取舍的才是经验。
3. **宁可少，不可假。** 没有数字就写定性，没做过就不写。

## 边界声明

本仓库内容均为个人方法论总结与脱敏后的设计描述。
不包含任何雇主的源代码、需求文档、用户数据、商业机密或内网信息。
如涉及具体项目，一律使用类型化描述（如"某休闲游戏项目"）。
